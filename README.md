# ClashRoyaleInfoApp

Una app Android en Kotlin para consultar y visualizar información de Clash Royale: cartas, arenas, cofres y estadísticas clave. Orientada a un diseño limpio, rendimiento estable y un código fácil de mantener.

---

## Características

- **Exploración de cartas:** Lista filtrable por tipo, rareza y coste.
- **Detalle de carta:** Imagen, estadísticas, sinergias y counters comunes.
- **Búsqueda rápida:** Por nombre y atributos con resaltado de resultados.
- **Favoritos:** Marcado local de cartas y acceso rápido.
- **Modo oscuro:** UI adaptativa y consistente.
- **Estado sin conexión:** Caché básica para últimos datos consultados.

---

## Requisitos

- **Android Studio:** Giraffe o superior
- **SDK mínimo:** 23
- **Lenguaje:** Kotlin
- **Gradle:** Kotlin DSL
- **Compatibilidad:** ARM64 y x86_64
